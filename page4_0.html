💾 Les Variables en JavaScript

Espace de stockage, Déclaration et Affectation

1. Qu'est-ce qu'une Variable ?

Pour faire simple, une variable est un espace de stockage sur votre ordinateur qui permet d'enregistrer tout type de donnée (chaîne de caractères, valeur numérique, structures plus complexes, etc.).

En JavaScript (JS), une variable est déclarée sans spécifier de type de contenu à l'avance, car JS est un langage typé dynamiquement.

2. Déclaration et Affectation d'une Variable

2.1 Déclaration

  • La déclaration d'une variable sert à lui réserver un espace de stockage en mémoire.
  • Pour la déclarer, on utilise les mots-clés let (moderne) ou var (ancien).
  • Exemple de déclaration simple: 
    let maVariable;

2.2 Affectation

  • L'affectation est l'action de donner une valeur à la variable. Elle se fait avec le signe =.
  • Exemples d'affectation : 
    maVariable = 2; // Après la déclaration
// Ou en une seule ligne :
let maVariable = 2; // Déclaration et affectation simultanées
  • Il est possible de déclarer plusieurs variables à la fois en les séparant par des virgules: 
    let score, vies, niveau1;

2.3 Règles de nommage importantes

Règles à retenir :

  • Le nom doit contenir uniquement des caractères alphanumériques (A-Z, 0-9), l'underscore (_) et le dollar ($).
  • Il ne peut pas commencer par un chiffre.
  • Il ne peut pas être un mot-clé réservé par JavaScript.
  • JavaScript est sensible à la casse (maVariable est différent de mavariable).

3. Les Types de Variables (Typage Dynamique)

JavaScript est un langage typé dynamiquement (comme Python). Cela signifie que le type de donnée est vérifié pendant l'exécution, et une variable peut contenir n'importe quel type de donnée.

3.1 Type Numérique (Number) 🔢

Représente tout nombre : entiers, négatifs, scientifiques, décimaux, etc. 

let number = 5; // Un nombre entier

3.2 Type Texte (String) 💬

Représente une chaîne de caractères. L'affectation peut se faire avec des guillemets doubles ("...") ou des apostrophes droites ('...'). 

let text1 = "Mon premier texte";
let text2 = 'Mon deuxième texte';

4. Les Calculs et la Concaténation

4.1 Réalisation de Calculs

Faire des calculs en programmation est simple. On peut utiliser des valeurs directes ou des variables contenant des nombres. 

let nombre1 = 3, nombre2 = 2;
let resultat = nombre1 * nombre2; // 'resultat' vaut 6

4.2 Simplification des calculs (Incrémentation)

Pour l'incrémentation (ajouter un nombre à la valeur de la variable), une forme simplifiée existe pour éviter la répétition.

Forme Longue (rébarbative) Forme Courte (simplifiée)
nombre = nombre + 5; nombre += 5;

4.3 La Concaténation avec le signe +

Le signe + est utilisé non seulement pour l'addition numérique, mais aussi pour l'ajout de texte, appelé concaténation. 

let chaine1 = "MMI1 - ";
let chaine2 = "Béziers";
let resultat = chaine1 + chaine2; // 'resultat' contient "MMI1 - Béziers"
