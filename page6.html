🔁 Fonctions en JavaScript

1. Les Fonctions (function)

Une fonction est un bloc de code réutilisable qui ne s'exécute que lorsqu'il est appelé.

1.1 Caractéristiques et Syntaxe

function maFonction( arguments ) {
    // Le code que la fonction va devoir exécuter
}
  • Le mot-clé function est obligatoire pour chaque déclaration.
  • On peut utiliser l'instruction break pour arrêter une boucle en cours de fonctionnement.
  • Les arguments servent à fournir des informations à la fonction lors de son exécution (comme le message passé à 'alert()').
  • Le code entre les accolades ne s'exécute que si la fonction est appelée.

Attention : Portée des variables
Toute variable déclarée à l'intérieur d'une fonction est une variable locale et n'est utilisable que dans cette même fonction.

1.2 Exemple avec arguments et DOM

Exécution d’une fonction en cliquant sur un bouton avec passage d’un argument pour modifier le style du corps de la page (DOM : Document Object Model). 

<script type="text/javascript">
function rouge(couleurfond){
    document.body.style.background = couleurfond;
    alert('La couleur du fond est maintenant en : ' + couleurfond);
}
</script>
<div id="bouton1"><button onclick="rouge('red'); ">fond rouge</button></div>

1.3 Arguments multiples

Il est possible de passer plusieurs arguments à une fonction, en les séparant par des virgules dans la déclaration : 

function multiples_arguments(premier, second) {
    alert('Votre premier argument : ' + premier);
    alert('Votre deuxième argument : ' + second);
}
// Lors de l'appel, les valeurs sont passées dans l'ordre.
