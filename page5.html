🧭 Exercice : Menu d’orientation du BUT MMI (Structure switch)

1. Contexte : Les Parcours du BUT MMI

Cet exercice pratique vise à mettre en œuvre la structure conditionnelle switch pour orienter un utilisateur vers les différents parcours de notre département MMI.

Les choix possibles pour l'utilisateur sont :

  • 1 : Création Numérique
  • 2 : Développement Web et dispositifs interactifs
  • 3 : Stratégie de communication numérique et design d’expérience

2. Tâches de Programmation

Objectif : Créer une interface d'aide à l'orientation

  1. Demander à l’utilisateur de choisir un parcours (de 1 à 3) via la fonction prompt().
  2. Utilisez un switch sur la valeur saisie pour afficher (avec alert()) une description courte du pôle choisi pour les choix 1, 2 et 3.
  3. Si la saisie est invalide (hors 1, 2 ou 3), afficher un message d'erreur via la commande default.

Contraintes techniques :

  • ✔️ Utiliser la fonction parseInt() pour convertir la saisie (qui est une chaîne de caractères) en nombre.
  • ✔️ Mettre un break à la fin de chaque case.
  • ✔️ Ajouter un default pour gérer toutes les saisies hors de la plage 1-3 (incluant les nombres négatifs ou 'NaN' si l'utilisateur annule ou entre du texte).
