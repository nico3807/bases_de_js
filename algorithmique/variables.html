Chapitre 2

Les variables : des boîtes étiquetées

Un programme a besoin de mémoriser des informations : un score, un prénom, le nombre d'articles dans un panier. Pour cela, on utilise des variables.

Une variable, c'est une boîte

Imaginez la mémoire de l'ordinateur comme une étagère remplie de boîtes. Une variable est une boîte qui porte une étiquette (son nom) et qui contient une valeur. On peut à tout moment regarder ce qu'il y a dans la boîte, ou remplacer son contenu.

Une boîte ne contient qu'une seule valeur à la fois : y ranger une nouvelle valeur écrase l'ancienne.

Déclarer et affecter

Déclarer une variable, c'est créer la boîte. Affecter une valeur, c'est la ranger dedans. En JavaScript, on déclare avec le mot-clé let (ou const pour une valeur qui ne changera jamais).

Pseudo-code

VARIABLES score : entier
DÉBUT
  score ← 0
  score ← score + 10
  AFFICHER score
FIN

JavaScript

let score = 0;
score = score + 10;
console.log(score); // 10

Le signe = ne veut pas dire « égal »

En mathématiques, score = score + 10 est absurde. En programmation, le = est une affectation et se lit de droite à gauche : « calcule score + 10, puis range le résultat dans score ». C'est pourquoi le pseudo-code utilise une flèche ←. Pour comparer deux valeurs, JavaScript utilise === (voir le chapitre suivant).

Bien nommer ses variables

  • Un nom parlant : prixTotal plutôt que x ou pt. Vous vous relirez dans trois semaines, votre binôme aussi.
  • Convention JavaScript : le camelCase (nombreDeLikes, estConnecte).
  • Pas d'espace, pas d'accent, pas de tiret, et le nom ne commence pas par un chiffre.
  • JavaScript distingue majuscules et minuscules : age et Age sont deux boîtes différentes.

Les types de valeurs

Chaque valeur a un type, qui détermine ce que l'on peut faire avec :

Type Exemples Utilisation typique
Nombre (number) 42, -3, 19.99 Scores, prix, positions, tailles en pixels.
Chaîne de caractères (string) "Bonjour", 'MMI', "42" Textes : prénoms, messages, contenu d'un champ de formulaire.
Booléen (boolean) true, false Un état vrai / faux : connecté ou non, menu ouvert ou fermé.

Les opérations

Sur les nombres

  • + - * / : les quatre opérations.
  • % (modulo) : le reste de la division entière. 17 % 5 vaut 2. Très utile pour savoir si un nombre est pair (n % 2 vaut 0).
  • Math.floor(7.8) : arrondi à l'entier inférieur (7).

Sur les chaînes

  • + colle (concatène) deux textes : "Hello" + " MMI" donne "Hello MMI".
  • texte.length : le nombre de caractères.
  • texte.toUpperCase() : le texte en majuscules.

Piège classique : "5" + 3

Si l'une des deux valeurs est une chaîne, + colle au lieu d'additionner : "5" + 3 donne "53". C'est exactement ce qui arrive avec prompt(), qui renvoie toujours une chaîne. D'où le parseInt() que nous verrons dans le TD Variables, calculs et interaction.

Essayez de retirer les parenthèses autour de age + 10 : que se passe-t-il, et pourquoi ?

Exécution pas à pas : échanger deux variables

Problème classique : on veut échanger le contenu de a et b. Écrire a = b; puis b = a; ne marche pas : dès la première ligne, l'ancienne valeur de a est écrasée et perdue. Comme pour échanger le contenu de deux verres, il faut un troisième récipient.

Que vaut x à la fin de ce programme ?

let x = 4;
let y = x * 2;
x = y + 1;
y = 0;

y reçoit 4 × 2 = 8, puis x reçoit 8 + 1 = 9. Modifier y ensuite ne change pas x : l'affectation a copié une valeur, elle n'a pas créé de lien entre les deux boîtes.

Qu'affiche console.log("Total : " + 2 + 3); ?

Le calcul se fait de gauche à droite : "Total : " + 2 donne la chaîne "Total : 2", à laquelle on colle 3. Pour obtenir 5, il faut des parenthèses : "Total : " + (2 + 3).

À retenir

  • Une variable = un nom + une valeur. On la déclare une fois avec let.
  • = range une valeur, de droite à gauche. La nouvelle valeur écrase l'ancienne.
  • Trois types de base : nombre, chaîne, booléen. + additionne les nombres mais colle les chaînes.
