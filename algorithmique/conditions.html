Chapitre 3

Les conditions : faire des choix

Jusqu'ici, nos programmes exécutaient toutes leurs lignes, de haut en bas. Une condition permet de n'exécuter certaines instructions que si une situation est vraie : afficher un message d'erreur si le mot de passe est trop court, changer de niveau si le score dépasse 100…

Des questions à réponse vrai / faux

Une condition est une expression dont le résultat est un booléen : true (vrai) ou false (faux). On l'obtient le plus souvent en comparant deux valeurs :

Opérateur Signification Exemple (avec age = 17)
===égal à (valeur et type)age === 18 → false
!==différent deage !== 18 → true
< / >strictement inférieur / supérieurage < 18 → true
<= / >=inférieur / supérieur ou égalage >= 18 → false

= , == ou === ?

= range une valeur (affectation). === compare deux valeurs. Il existe aussi ==, qui compare en convertissant les types ("5" == 5 est vrai !) : prenez l'habitude d'utiliser ===, plus prévisible.

SI … ALORS … SINON

Pseudo-code

SI motDePasse.longueur < 8 ALORS
  AFFICHER "Trop court"
SINON
  AFFICHER "Mot de passe accepté"
FIN SI

JavaScript

if (motDePasse.length < 8) {
  console.log("Trop court");
} else {
  console.log("Mot de passe accepté");
}
  • La condition se place entre parenthèses après if.
  • Les instructions à exécuter se placent entre accolades { }. On les indente (décale vers la droite) pour voir d'un coup d'œil ce qui dépend de la condition.
  • Le bloc else (sinon) est facultatif.
  • Un seul des deux blocs est exécuté, jamais les deux.

Plusieurs cas : SINON SI

Quand il y a plus de deux possibilités, on enchaîne les tests avec else if. Les conditions sont testées dans l'ordre, et dès qu'une est vraie, son bloc est exécuté et les suivantes sont ignorées.

Exemple : un cinéma applique le tarif enfant (5 €) avant 14 ans, le tarif jeune (7,50 €) avant 26 ans, et le plein tarif (11 €) sinon. Changez l'âge de départ et observez quel chemin prend le programme.

Un·e camarade a écrit ce code. Qu'affiche-t-il pour age = 10 ? 

if (age < 26) {
  console.log("Tarif jeune");
} else if (age < 14) {
  console.log("Tarif enfant");
}

10 < 26 est vrai : le premier bloc est exécuté et le else if n'est même pas testé. Le tarif enfant ne sera jamais affiché ! Dans une suite de else if, l'ordre des tests est essentiel : on va du cas le plus restrictif au plus général.

Combiner des conditions : ET, OU, NON

Pour tester plusieurs choses à la fois, on combine les conditions avec les opérateurs logiques :

&& : ET

Vrai seulement si les deux conditions sont vraies.

age >= 18 && aLePermis

|| : OU

Vrai si au moins une des deux conditions est vraie.

jour === "samedi" || jour === "dimanche"

! : NON

Inverse une condition : vrai devient faux, faux devient vrai.

!estConnecte

À retenir

  • Une condition vaut true ou false. On compare avec ===, !==, <, >, <=, >=.
  • if / else if / else : un seul bloc est exécuté, le premier dont la condition est vraie.
  • && exige tout, || se contente d'un seul, ! inverse.
