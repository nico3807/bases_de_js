Les bases de l'algorithmique

Avant d'écrire du JavaScript, il faut savoir quoi dire à l'ordinateur. L'algorithmique, c'est l'art de découper un problème en étapes simples, précises et dans le bon ordre. Ces pages vous font découvrir les briques de base que l'on retrouve dans tous les langages.

Pourquoi en MMI ?

Un carrousel d'images, un quiz, un panier d'achat, un mini-jeu : derrière chaque interaction d'un site se cache un algorithme. Le savoir le concevoir, c'est ne plus dépendre d'un code copié-collé.

Comment ?

Chaque notion est présentée deux fois : en pseudo-code (du français structuré, pour réfléchir) puis en JavaScript (pour que l'ordinateur l'exécute).

Outils

Tout se fait dans ces pages : un exécuteur pas à pas pour voir le programme tourner ligne par ligne, et des zones de code à modifier et exécuter directement.

Le parcours

Suivez les chapitres dans l'ordre : chacun s'appuie sur le précédent. Chaque chapitre se termine par un lien vers les exercices correspondants.

  • 1. Penser comme un algorithme - Qu'est-ce qu'un algorithme ? Entrées, traitement, sorties, et pourquoi l'ordinateur a besoin d'instructions sans ambiguïté.
  • 2. Variables et types - Ranger des valeurs dans des « boîtes », les calculer, les modifier. Nombres, textes et booléens.
  • 3. Les conditions - Faire des choix : SI … ALORS … SINON, comparaisons et opérateurs logiques ET / OU / NON.
  • 4. Les boucles - Répéter sans recopier : POUR quand on connaît le nombre de tours, TANT QUE sinon.
  • 5. Les tableaux - Manipuler une liste de valeurs et les algorithmes classiques : somme, moyenne, maximum, recherche.
  • 6. Les fonctions - Découper un programme en sous-programmes réutilisables, avec des paramètres et une valeur de retour.
  • Exercices - 18 exercices corrigés automatiquement, du plus simple au défi.
  • Et ensuite : TD Bases du JavaScript - Installer VS Code et réutiliser ces briques pour rendre une vraie page web interactive.

Objectifs

Savoir-faire technique

  • Déclarer, affecter et afficher une variable.
  • Écrire une condition simple et une condition multiple.
  • Choisir entre une boucle for et une boucle while.
  • Parcourir un tableau pour calculer une somme, un maximum, un compte.
  • Écrire une fonction avec paramètres et return.

Façon de penser

  • Décrire un problème en étapes avant de toucher au clavier.
  • « Jouer l'ordinateur » : exécuter un algorithme à la main, en suivant la valeur de chaque variable.
  • Tester son programme avec plusieurs valeurs, y compris les cas limites.
  • Lire un message d'erreur au lieu de le fuir.

Comment travailler avec ces pages

Les blocs « Exécution pas à pas » se pilotent avec le bouton Suivant ▶ : la ligne jaune est celle qui vient d'être exécutée, les boîtes surlignées sont les variables qui viennent de changer. Prenez le temps de prédire ce qui va se passer avant chaque clic.

Les blocs « À vous de jouer » sont de vraies zones de code : modifiez-les, puis cliquez sur ▶ Exécuter (ou Ctrl+Entrée). Ce que le programme écrit avec console.log() s'affiche en dessous.

Le bon réflexe

Un algorithme se prépare sur papier (ou en pseudo-code) avant d'être codé. Si vous ne savez pas expliquer en français ce que votre programme doit faire, JavaScript ne vous aidera pas : il fera exactement ce que vous lui dites, pas ce que vous pensiez lui dire.
