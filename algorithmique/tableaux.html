Chapitre 5

Les tableaux : des listes de valeurs

Une galerie de 30 photos, les notes d'une promo, les articles d'un panier : créer une variable par valeur serait ingérable. Un tableau range toutes ces valeurs dans une seule variable, en les numérotant.

Un tableau, c'est une rangée de cases numérotées

let notes = [12, 8, 15, 9];
12
0
8
1
15
2
9
3
  • On écrit un tableau entre crochets, valeurs séparées par des virgules.
  • Chaque case a un numéro, son indice, qui commence à 0. La première note est notes[0], la deuxième notes[1]…
  • notes.length donne le nombre de cases (ici 4). La dernière case est donc notes[notes.length - 1].

Pseudo-code

notes ← [12, 8, 15, 9]
AFFICHER notes[0]        // 12
notes[1] ← 10            // remplace le 8
AJOUTER 14 À LA FIN DE notes
AFFICHER TAILLE(notes)   // 5

JavaScript

let notes = [12, 8, 15, 9];
console.log(notes[0]);      // 12
notes[1] = 10;              // remplace le 8
notes.push(14);             // ajoute à la fin
console.log(notes.length);  // 5

Le décalage de 1

Un tableau de 4 cases a les indices 0, 1, 2 et 3. notes[4] n'existe pas : JavaScript renvoie undefined sans erreur, ce qui rend le bug discret. C'est l'erreur la plus fréquente avec les tableaux, dans tous les langages.

Parcourir un tableau

Pour traiter chaque case, on combine un tableau et une boucle for : le compteur i sert d'indice et va de 0 à length - 1. C'est la boucle à connaître par cœur :

Pseudo-code

POUR i DE 0 À TAILLE(notes) - 1 FAIRE
  AFFICHER notes[i]
FIN POUR

JavaScript

for (let i = 0; i < notes.length; i++) {
  console.log(notes[i]);
}

Les algorithmes classiques

Quatre schémas reviennent sans cesse. Ils ont tous la même structure : une variable préparée avant la boucle, mise à jour pendant, utilisée après.

Somme et moyenne

let somme = 0;
for (let i = 0; i < notes.length; i++) {
  somme = somme + notes[i];
}
let moyenne = somme / notes.length;

Compter

let nbReussites = 0;
for (let i = 0; i < notes.length; i++) {
  if (notes[i] >= 10) {
    nbReussites = nbReussites + 1;
  }
}

Chercher le maximum

Comment trouveriez-vous la meilleure note d'une copie à l'autre, sans tout voir d'un coup ? On retient la meilleure note vue jusqu'ici, et on la remplace chaque fois qu'on trouve mieux. Au départ, la « meilleure vue jusqu'ici » est simplement la première.

Pourquoi initialise-t-on max avec notes[0] plutôt qu'avec 0 ?

Avec des températures comme [-5, -2, -9], partir de 0 donnerait un maximum de 0. Partir de la première case garantit que le résultat est toujours une valeur réelle du tableau. C'est un cas limite, à penser systématiquement quand on teste son code.

Rechercher une valeur

Pour savoir si un élément est présent, on parcourt le tableau jusqu'à le trouver. Inutile de continuer une fois trouvé : on utilise un while avec une double condition, et un booléen qui mémorise si on a trouvé.

À retenir

  • Les indices commencent à 0 ; le dernier est length - 1.
  • Parcours : for (let i = 0; i < tab.length; i++), et tab[i] dans la boucle.
  • Somme, compteur, maximum, recherche : une variable avant, une mise à jour pendant, un résultat après.
