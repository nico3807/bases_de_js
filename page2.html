⚙️ Premières pages JavaScript avec VS Code

1. Création d'un projet, premier site

Sur VS Code, chaque site ou projet de développement est stocké dans un dossier.

Pour créer votre premier site avec Visual Studio Code, réalisez les actions suivantes :

  1. Créer sur votre ordinateur un dossier qui contiendra votre site.
  2. Ouvrir ce dossier avec Visual Studio Code.
  3. Créer (via Visual Studio Code) un nouveau fichier nommé index.html.
  4. Dans ce fichier, tapez le caractère ! puis la touche Entrée. Vous obtiendrez une page web opérationnelle sans contenu.
  5. Réalisez un clic droit sur le fichier et choisissez Open with Live Server. La page web doit s'ouvrir dans le navigateur par défaut.
  6. La page web est désormais mise à jour et synchronisée avec l'éditeur de code.

Modification du HTML

Modifiez le fichier HTML pour y ajouter :

  • une balise <h1> avec un titre,
  • une division <DIV> contenant deux paragraphes de textes Lorem Ipsum.

Sauvegardez et observez immédiatement le résultat dans le navigateur.

2. Premier script JavaScript

Pour écrire du JavaScript, deux solutions sont possibles:

  • Écrire le code directement dans la page HTML entre une balise <script> et une balise </script>.
  • Écrire le code dans un fichier dédié et l'intégrer dans la page HTML avec la balise <script src=URL></script>.

La seconde méthode est à privilégier car elle permet de bien séparer les différentes parties d'un site web : HTML, CSS, JS, PHP, ...

Intégration du Script

Complétez le projet existant:

  1. Ajoutez au projet un nouveau fichier nommé script.js.
  2. Ajoutez la balise suivante à la fin du fichier HTML, juste avant la balise </body>: 
    <script src="script.js"></script>

Regardez s'il y a eu un effet sur la page web. Vous ne devriez normalement observer aucun effet visible sur la page web.

Dans la suite, toutes les instructions JavaScript seront ajoutées dans le fichier script.js.

3. Outils de développement du navigateur

Ouvrez les outils de développement du navigateur. En règle générale, il suffit de réaliser un "clic droit" sur la page web et de choisir "Examiner l'élément" ou "Inspecter".

(Note : Les captures d'écran ci-dessous correspondent au navigateur Google Chrome, mais les outils sont similaires sur Firefox, Edge, etc.)

Ces outils sont essentiels lors de la phase de création d'un site web. Vous y retrouvez notamment:

  • le sélecteur d'élément HTML
  • la console JavaScript (outil clé pour le débogage de code JS)
  • l'inspecteur de code HTML
  • le débogueur
  • l'outil de mesure des performances
  • l'analyseur de l'activité réseau
  • les éléments stockés (Local Storage, Cookies, etc.)

Vous pouvez installer différents plugins à votre navigateur pour vous aider à développer des pages web conformes aux recommandations du consortium W3C.
