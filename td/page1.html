🛠️ Prise en main de VS Code

Cette partie a pour objectif de vous familiariser avec Visual Studio Code (VS Code), l'outil que nous utiliserons tout au long de votre formation en développement web.

1. Installation et Découverte

Nous utiliserons l'outil Visual Studio Code qui est disponible gratuitement pour tous les systèmes d'exploitation (Windows, Linux et macOS).

Visual Studio Code est un éditeur de code extensible développé par Microsoft pour Windows, Linux et macOS.

Ses fonctionnalités incluent:

  • La prise en charge du débogage
  • La mise en évidence de la syntaxe
  • La complétion intelligente du code
  • Les snippets
  • La refactorisation du code
  • Git intégré

Les utilisateurs peuvent également modifier le thème, les raccourcis clavier, les préférences et installer des extensions qui ajoutent des fonctionnalités supplémentaires.

1.1 Téléchargement et Lancement

Commencez par télécharger et installer cet outil depuis le site officiel : https://code.visualstudio.com/.

Une fois installé, lancez VS Code. La fenêtre principale suivante devrait apparaître (elle peut varier en fonction de vos réglages) :

2. Extensions pour Visual Studio Code

Il existe de très nombreuses extensions pour Visual Studio Code permettant d'améliorer significativement les fonctionnalités de l'outil et ainsi de le personnaliser.

2.1 Installation des Extensions de Base

Sur la barre des outils de gauche, repérez et cliquez sur l'icône Extensions:

Vous devez rechercher puis installer les extensions suivantes qui faciliteront votre travail:

  • Live Server : Lance un serveur web local pour voir les modifications en temps réel. Avec cette extension, votre ordinateur hébergera à la fois un serveur web et le navigateur client sur le même poste.
  • Prettier : Formate automatiquement le code pour un style cohérent.
  • Prettify JSON : Organise et rend le JSON plus lisible.
  • Bracket Pair Colorize : Colore les paires de parenthèses pour une meilleure lisibilité.
  • French - Code Spell Checker : Corrige les fautes d'orthographe en français dans le code.
  • French Language Pack for Visual Studio Code : Traduit l'interface en français.
  • Lorem ipsum : Génère du texte factice pour les tests (souvent utilisé pour des maquettes).

3. Personnalisation des Raccourcis Clavier

Vous avez la possibilité de personnaliser les raccourcis clavier associés aux extensions.

Exemple d'activité : Pour associer un raccourci clavier permettant d'ajouter un paragraphe de texte Lorem ipsum, suivez les étapes suivantes :

  1. Cliquez sur :
    • Fichier -> Préférences -> Raccourcis clavier (pour Windows), OU
    • Code -> Réglages -> Raccourcis clavier (pour Mac Os X).
  2. Tapez 'lorem' dans la barre de recherche.
  3. Choisissez le raccourci clavier pour l'action Lorem Ipsum: Insert a paragraph.
