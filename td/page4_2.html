🚦 Les boucles de répétition

1. Les Boucles (Répétition d'instructions)

Une boucle permet de répéter un bloc de code tant qu'une condition reste vraie (true). La boucle s'arrête dès que la condition devient fausse (false).

2.1 La boucle while

La boucle while (tant que) exécute le code tant que la condition est remplie. Si la condition est fausse dès le départ, le code n'est jamais exécuté. 

let nombre = 1;
while (nombre < 10) { // Condition: Tant que nombre est strictement inférieur à 10
    nombre++; // Incrémentation
}
alert(nombre); // Affiche : « 10 »

On peut utiliser l'instruction break pour arrêter une boucle en cours de fonctionnement.

2.2 La boucle do while

La boucle do while ressemble à while, mais la boucle est toujours exécutée au moins une fois. La condition est testée *après* le premier passage. 

do {
    instruction_1;
    instruction_2;
}
while (condition);

3. Les Boucles : Répétition avec `for`

Les boucles permettent d'exécuter un même bloc de code plusieurs fois de suite, souvent pour automatiser une tâche ou parcourir une liste de données.

La boucle for est la plus courante pour la répétition d'un code un nombre de fois déterminé.

Elle prend trois paramètres entre parenthèses, séparés par des points-virgules :

Paramètre Rôle Exemple
1. Initialisation Déclare et initialise le compteur (ex: i = 0). let i = 0
2. Condition Condition à vérifier. Tant qu'elle est vraie, la boucle continue. i < 5
3. Incrémentation Action à effectuer à la fin de chaque tour (souvent : augmenter le compteur). i++

L'opérateur i++ est une forme simplifiée pour dire i = i + 1 (incrémenter de 1). 

// Affichera "Tour numéro X" cinq fois (pour i allant de 0 à 4)
for (let i = 0; i < 5; i++) {
    console.log("Tour numéro " + i);
}
