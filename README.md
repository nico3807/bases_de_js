# Développement web - BUT MMI 1 (R1.12)

Supports de cours pour découvrir la programmation avec JavaScript.
Ouvrir `index.html` à la racine (double-clic ou Live Server).

```
bases_de_js/
├── index.html          Page d'accueil : liens vers les deux parcours
├── algorithmique/      Les bases de l'algorithmique (voir son README)
│   ├── *.html
│   ├── css/  img/  js/
└── td/                 TD - Bases du JavaScript
    ├── index.html      Menu du TD
    ├── page*.html      Les pages du TD
    ├── css/style.css
    ├── img/            Captures d'écran
    └── exemples/       Fichiers d'exemples et d'exercices
```

La page d'accueil réutilise la feuille de style de `algorithmique/` pour
garder la même charte graphique.
