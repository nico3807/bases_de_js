⚙️ Les structures conditionnelles et boucles

1. Les Structures Conditionnelles (`if/else`)

Les structures conditionnelles permettent de contrôler l'exécution du code en fonction de l'évaluation d'une condition. Si la condition est `true` (vraie), le bloc de code est exécuté.

1.1 La structure simple `if` et `else`

Le bloc `if` exécute le code si la condition est vraie. Le bloc `else` est optionnel et est exécuté si la condition est fausse ("sinon"). 

let age = 18;

if (age >= 18) { // Si la condition est VRAIE
    alert("Vous êtes majeur.");
} else { // SINON, si la condition est FAUSSE
    alert("Vous êtes mineur.");
}
Rappel des Opérateurs : N'oubliez pas les opérateurs de comparaison (>, <, >=, <=, ==, ===, !=) et les opérateurs logiques (&& pour ET, || pour OU, ! pour NON).

Ces opérateurs permettent de comparer des valeurs ou de combiner des conditions.

Opérateurs de conditions et logiques

Opérateur de Comparaison Signification
== égal à (juste le contenu, peu importe le type)
=== contenu et type égal à
!= différent de
> supérieur à
<= inférieur ou égal à
Opérateur Logique Type de logique
&& ET (valeur1 ET valeur2)
|| OU (valeur1 OU valeur2)
! NON (!valeur)

1.2 La structure `else if`

Pour vérifier plusieurs conditions successives, on utilise la structure else if. Dès qu'une condition est vraie, les suivantes sont ignorées. 

let score = 85;

if (score >= 90) {
    alert("Niveau A");
} else if (score >= 80) { // Testé uniquement si la première condition est FAUSSE
    alert("Niveau B");
} else { // Si toutes les conditions sont FAUSSES
    alert("Niveau C");
}

2. La Fonction de Choix Multiple (`switch`)

La fonction switch est une alternative plus lisible à une longue série de if... else if... lorsque l'on compare une seule variable à de multiples valeurs spécifiques.

  • L'instruction case vérifie si la variable correspond à une certaine valeur.
  • L'instruction break est essentielle. Elle arrête l'exécution du switch une fois qu'un cas correspond. Sans elle, le code passe au cas suivant.
  • L'instruction default est exécutée si aucune des valeurs de case ne correspond. C'est l'équivalent du else final. 
let jour = "mardi";
let message = "";

switch (jour) {
    case "lundi":
        message = "Bon début de semaine !";
        break; // Sort de la structure switch
    case "vendredi":
        message = "C'est bientôt le week-end !";
        break;
    default:
        message = "Journée classique.";
}
alert(message);
